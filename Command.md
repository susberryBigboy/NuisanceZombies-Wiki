# Commands

Some commands cannot be operated via the GUI and are explained below.

---

## 🛡️ Admin Commands

### `/nz get_server_config`
* Loads the current server configuration.
* This updates the config GUI, allowing you to edit the settings directly afterwards.

### `/nz reset`
* Resets all server-side configurations back to their default values.

### `/nz show_config`
* Displays the current server configuration settings in the chat window.
* *Note: This only displays the settings and does not load them.*

### `/nz block <zombie|zombified_piglin> <block>`
* Sets the specific blocks that designated mobs will utilize or interact with.

---

## 👤 General Player Commands (All Players)

### `/nz show_personal_settings`
* Displays your individual personal settings currently configured on the server.
