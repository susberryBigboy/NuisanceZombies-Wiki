# Enhanced Weapons & Features

To help players survive in such a punishing world, several weapon mechanics and enchantments have been enhanced to balance the battlefield.

---

## ⚔️ Enhanced Mechanics

* **Axes with Mace Enchantments:** Mace-exclusive enchantments can now be applied directly to axes.
* **Spear Lunge:** Using the Lunge ability with spears no longer consumes hunger/saturation points.
* **Expanded Bow Enchantments:** Bows can now simultaneously accept **Infinity**, **Mending**, **Multishot**, and **Unbreaking**.

---

## 🎯 Homing Arrows

* **Built-in Homing:** All bows are equipped with a built-in homing capability that automatically tracks target hostiles.
* **Multishot Support:** The homing effect fully applies to every arrow fired via the Multishot enchantment.
* **Configurable:** This feature can be easily disabled in the configuration settings if preferred.
